# 껴보링

> 사기 전에, 내 손에 먼저 껴 봐요.

내 손을 3초 찍으면, 그 영상 위에 3D 반지를 실제 크기(mm)로 끼워 보는 웹앱입니다.
반지를 옆으로 넘기면서 바로바로 바꿔 끼고, 다섯 손가락 어디든 끼우고, 가드링을 겹쳐 끼워 볼 수 있어요.

## 할 수 있는 것

| 기능           | 설명                                                                                    |
| -------------- | --------------------------------------------------------------------------------------- |
| 손 촬영        | 페이지 안에서 바로 카메라를 켜 3초 동안 40장을 찍어요. 앨범의 손 영상도 올릴 수 있어요. |
| 반지 넘겨 보기 | 아래 휠에서 반지를 넘기면 가운데 온 반지가 바로 손에 끼워져요. (14종)                   |
| 다섯 손가락    | 엄지부터 소지까지 손가락마다 따로 끼울 수 있어요.                                       |
| 자세히 설정    | 색상(로즈·옐로·화이트골드), 폭, 파베, 가드링 두께(1.0~2.5mm)                            |
| 원스톤 링      | 컷(라운드, 오벌, 프린세스 등 7종) × 캐럿 × 알 종류를 골라 만들어요.                     |
| 내 호수        | 5~25호(0.5 단위). 호수에 맞춰 반지 크기가 바뀌어요.                                     |
| 세트 저장      | 끼운 반지 조합을 저장하고, 나중에 "다시 껴 보기"로 그대로 불러와요.                     |

서버와 DB, 로그인은 없어요. 세트 저장은 기기 안(localStorage)에만 남아요.

## 어떻게 동작하나요

```
3초 촬영 → 손 점 21개 찾기 → 손가락 굵기 재기 → 반지 크기·위치 정하기 → 손가락 뒤쪽 가리기
```

**1. 촬영** (`LiveCapture.tsx`)
`getUserMedia`로 페이지 안에서 카메라를 켜고 3초 동안 40장을 뽑아요. 휴대폰 기본 카메라로 찍어 올리면 영상이 압축돼서 화질이 떨어지는데, 이렇게 하면 압축을 거치지 않아요.

**2. 손 찾기** (`hand/analyze.ts`, `hand/smooth.ts`)
MediaPipe Hand Landmarker로 프레임마다 손 관절 점 21개를 찾아요. 프레임마다 점이 조금씩 흔들리면 반지만 따로 떨려 보여서, 앞뒤 5프레임을 [1, 2, 3, 2, 1] 가중 평균으로 부드럽게 만들어요.

**3. 손가락 굵기 재기** (`hand/skin.ts`, `hand/width.ts`, `hand/fixed.ts`)
MediaPipe 이미지 분할로 피부 영역을 구한 뒤, 손가락 가운데에서 손가락과 수직 방향으로 걸어가며 양쪽 경계를 찾아요. 손가락끼리 붙어 있어서 피부가 끊기지 않으면, 손가락 사이 틈(가장 어두운 곳)을 경계로 써요. 여러 프레임에서 잰 값의 가운데값을 그 손가락의 굵기로 고정해요.

**4. 크기와 위치** (`hand/pose.ts`)

- 크기: 반지 안쪽 둘레(mm) = 40 + 호수. 여기서 나온 안쪽 지름과, 화면에서 잰 손가락 굵기(px)를 맞춰 mm와 px 비율을 정해요.
- 위치: 손가락이 갈라지는 곳에서 (반지 폭의 절반 + 1.5mm)만큼 위에 반지를 놓아요. 손이 가까워지거나 멀어지면 관절 길이에 비례해 크기도 같이 바뀌어요.

**5. 손가락 뒤쪽 가리기** (`three/occluders.ts`)
관절 점 사이마다 **보이지 않는 원기둥**을, 마디마다 작은 공을 세워 3D 손가락을 만들어요. 이 손가락은 색은 그리지 않고 깊이 정보만 남겨요(`colorWrite: false`, 가장 먼저 그림). 그래서 반지 중 손가락보다 뒤에 있는 부분은 그려지지 않고, 그 자리에 실제 손가락이 보여 반지가 손가락을 감싼 것처럼 보여요.

**6. 반지 그리기** (`three/makeRing.ts`, `three/sol.ts`, `three/layoutStones.ts`)
three.js로 반지를 실제 mm 치수로 만들어요. 밴드 단면, 표면 무늬, 파베 알 배치, 원스톤의 컷과 캐럿별 알 크기까지 수치로 계산해요. 반지 목록과 파베 설정은 `public/rings.json`에 있어요.

## 기술 스택

- Vite + React + TypeScript
- three.js (3D 반지, 가림 처리)
- @mediapipe/tasks-vision (손 관절, 피부 분할)
- 배포: Vercel(웹), 앱인토스(토스 미니앱)

## 폴더 구조

```
src/
  App.tsx, Landing.tsx, LiveCapture.tsx   화면 흐름, 첫 화면, 촬영
  HandStage.tsx, Wheel.tsx, Detail.tsx    손 화면, 반지 휠, 자세히 설정
  HoPicker.tsx, SetsList.tsx, sets.ts     호수 고르기, 세트 저장
  hand/      손 점 찾기, 굵기 재기, 반지 자리 계산 (화면과 무관한 순수 계산)
  three/     3D 장면, 반지 모양, 파베, 원스톤, 가림 원기둥
public/
  rings.json         반지 목록과 파베 설정
  mediapipe/         손 관절, 피부 분할 모델 파일
```

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 웹 빌드 + 앱인토스 번들(.ait)
npm run deploy    # 앱인토스 배포
```

휴대폰 카메라는 HTTPS에서만 켜져요. 휴대폰으로 테스트할 땐 Vercel 미리보기 주소를 쓰는 게 편해요.

## 앱인토스 설정

`apps-in-toss.config.ts`

- `appName: 'ring-on-it'` (토스 콘솔의 앱 이름과 같아야 해요)
- `webView.allowsInlineMediaPlayback: true`: iOS 토스 웹뷰가 카메라 화면을 전체화면 플레이어로 띄우지 않게 해요. 영상 태그에는 `playsInline`, `muted`도 같이 붙어 있어요.

## 만들 때 지킨 원칙

- 길이는 전부 mm 기준으로 계산해요.
- 휴대폰 세로, 라이트 모드만 지원해요. 핀치 줌은 막아 두었어요.
- 처음 들어왔을 때 바텀시트가 자동으로 튀어나오지 않아요. (토스 UX 규칙)
- 실제 브랜드 이름, 로고, 공식 사진은 쓰지 않아요.
